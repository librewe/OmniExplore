# 03 · 交互与状态

> 用户行为路径、UI 状态矩阵、交互协议、异常与边界

---

## 1. 核心用户行为路径

### 路径 0：初始界面（无术语聚焦）

```
用户首次打开应用
  → 自动创建"默认"工作组
  → 中列显示居中引导页：
     ┌──────────────────────────┐
     │                          │
     │     🌳 OmniExplore       │
     │  沿着概念根系递归追问     │
     │                          │
     │  [输入概念，按回车探索...] │
     │                          │
     │  最近: 预解式 · 泛函分析   │
     └──────────────────────────┘
  → 左列足迹为空，显示"在此追踪认知路径"
  → 输入术语回车 → 进入路径 A（树模式）
```

### 路径 A：首次探索（底部输入框发起）

```
用户打开页面
  → 底部输入框默认"🎯 聚焦"模式（无根节点）
  → 输入 "预解式"，回车
  → 检查 IndexedDB：
      ├─ 命中缓存 → 直接渲染
      └─ 未命中 → 创建 ConceptNode { term: "预解式" }
                  → 输入框自动切为"💬 追问"模式（有根默认追问）
                  → 左侧足迹追加 "预解式"（current_index = 0）
                  → 右侧树创建根节点 + 4 个预设子节点骨架
                  → 自动触发 micro_intuition LLM 生成（流式打字机）
                  → 其余 3 项折叠态，显示 "点击以探索 →"
```

### 路径 A2：有根时输入框聚焦模式

```
当前根为 "预解式"，用户手动切到"🎯 聚焦"模式
  → 输入 "泛函分析"，回车
  → 左侧足迹追加 "泛函分析" → 根切换为 "泛函分析" → 同路径 A
```

### 路径 B：双击聚焦（术语跳转 + 创建新节点）

```
用户在已展开的节点回答中看到虚下划线术语 "算子"
  → 双击 "算子"：
    1. 左侧足迹追加 "算子"（路径变为 预解式 → 算子）
    2. 检查 IndexedDB 是否有 term="算子" 的节点
       ├─ 有缓存 → 直接切换根节点为 "算子"，展示缓存内容
       └─ 无缓存 → 创建新 ConceptNode，自动生成动态直觉
```

> **关键**：双击聚焦 = 创建独立 ConceptNode + 切换根节点。追问 ≠ 创建独立节点。

### 路径 C：右键追问（填入输入框 → 编辑 → 发送）

```
用户在 "预解式" 的动态直觉中看到 "算子"，右键
  → 弹出菜单：🎯 设为焦点 | 💬 追问此术语 | ⚡ 换角度
  → 选择 "💬 追问此术语"：
    1. 底部输入框自动切到 "💬 追问" 模式
    2. 输入框填入 "算子是什么？"（可编辑）
    3. 用户编辑/确认 → 回车
    4. 追问节点挂在发起右键的节点下
    5. 子节点标题 = 输入框内容
    6. 子节点内容区 = 流式加载（打字机）
    7. 完成后永久保留 + 存入 custom_qa[]
```

### 路径 C2：底部输入框追问模式（直接输入）

```
当前有根节点 "预解式"，输入框为 "💬 追问" 模式
  → 输入 "谱集和谱半径关系？"，回车
  → 追问节点直接挂在根下（因为没有右键上下文）
  → 流式生成答案
```

### 路径 C3：+ 按钮创建预设追问

```
用户在 "预解式" 节点右侧点击 +
  → 下拉菜单：📖 添加参考 | ─── | "...是什么？" | "...为什么重要？" | ...
  → 选择 ""...是什么？""（{term}模板自动展开为 "预解式是什么？"）
  → 底部输入框填入 "预解式是什么？"（可编辑）
  → 回车 → 追问挂在 + 所在节点下 → 流式生成
```

### 路径 C4：+ 按钮添加参考

```
用户在任意节点右侧点击 +
  → 选择 "📖 添加参考"
  → 该节点下创建参考子节点（初始空 textarea）
  → 用户粘贴/上传文本 → 从术语表匹配标注（本地，不调 LLM）
  → 标注后的文本可双击/右键交互
  → 参考节点可拖拽到树中其他位置
```

### 路径 D：节点操作（选中 / 删除 / 撤销 / 重做）

```
用户单击节点（标题或内容区）
  → 节点高亮（蓝色背景）→ 节点处于选中态
  → 按 Delete → 节点移除 → Ctrl+Z 撤销 / Ctrl+Y 重做

用户双击节点标题
  → 标题进入内联编辑模式 → 修改 → 回车确认

用户双击节点内容区（参考/追问节点）
  → 内容进入编辑模式（textarea）→ 修改 → 点击外部保存
  → 预设四问内容不可直接编辑（通过"刷新"重生成）

用户右键节点
  → 弹出节点右键菜单：
     ✨ 刷新此节点（参考节点灰显）
     ✏️ 重命名
     🗑️ 删除
  → 选中 → 执行对应操作
```

### 路径 E：导图切换（树 ⇄ 导图）

```
用户在递归树模式聚焦某概念 → 按 Esc
  → 主区域切换到导图模式
  → 若该工作组 guide_map 为 null → 显示"生成导图"按钮
  → 若已有导图 → 显示教材目录式坐标，当前焦点高亮 ●
  → ✓ 标记已在术语库中的术语
  → 再按 Esc 或点 × → 回到树模式

用户在导图模式点击某节点
  → 聚焦跳转（同双击行为）
  → 切换到树模式
  → 足迹追加

用户在导图模式点 "Extend"
  → 调 LLM 增量扩展：传入已有导图 + 新探索术语
  → 流式返回更新后的导图 → 覆盖缓存
```

### 路径 F：工作组切换

```
用户在顶部栏切换工作组
  → 树/足迹/术语库/导图 全部切换到该组上下文
  → 若该组无活跃根节点 → 显示空状态引导
  → 若该组有根节点 → 恢复上次的根和展开状态（从缓存）
  → 组间数据完全隔离
```

### 路径 G：划词换角度（重新采样）

```
用户右键虚下划线术语 → ⚡ 换角度
  → 仅当该术语为当前节点的根时才可用（root-level resample）
  → 重新调用 LLM（同 Prompt 模板，不同 randomness）
  → 流式覆盖原答案 → 覆盖 IndexedDB 缓存
```

### 路径 H：视角切换（微观 ↔ 宏观）

```
用户点击右上角开关
  → 微观 → 宏观：
    1. 仅 4 个预设子节点的标签和内容替换为宏观版本
    2. 追问节点、参考节点保留不动
    3. 树展开/折叠状态完全保留
    4. 已展开预设节点：
       ├─ macro_* 字段有缓存 → 立即显示
       └─ macro_* 字段为 null → 显示 "点击以探索 →"
  → 宏观 → 微观：同理
```

### 路径 F：足迹回溯

```
用户在左侧足迹链中点击 "泛函分析"
  → 右侧树立即重置为 "泛函分析" 的根状态
    （包含所有已缓存的展开节点，已展开的维持展开态）
  → 左侧足迹截断：移除 "泛函分析" 之后的所有节点
  → current_index 移到 "泛函分析" 位置
```

## 2. 交互协议

### 2.1 虚下划线术语

```
渲染规则：
  - LLM 返回文本中的 [[术语]] → 渲染为 <span class="term-underline">
  - 虚下划线样式：text-decoration: underline dotted
  - 颜色：主题色（如 blue-500）

渲染范围：
  - 整棵树所有已展开节点的答案文本
  - 渲染时机：节点展开时 / 流式输出完成时
  - 不实时持续渲染（性能无忧）

交互：
  双击 → 聚焦跳转（路径 B）
  右键 → 弹出菜单（路径 C/D）
  悬停 → 气泡预览（从缓存提取动态直觉首句，200ms delay）
```

### 2.2 划词右键菜单

触发条件：右键点击虚下划线术语（`[[术语]]`）

| 选项 | 图标 | 行为 | 可用条件 |
|---|---|---|---|
| 设为焦点 | 🎯 | 等同于双击聚焦 | 始终可用 |
| 追问此术语 | 💬 | 术语填入底部输入框（追问模式），用户编辑后回车创建 | 始终可用 |
| 换角度 | ⚡ | 重新生成该术语所在节点的答案（仅根节点预设内容） | 术语所在节点为根节点的预设四问时可用 |

### 2.3 节点右键菜单

触发条件：右键点击节点标题或内容区（非虚下划线区域）

| 选项 | 图标 | 行为 | 可用条件 |
|---|---|---|---|
| 刷新此节点 | ✨ | 重新生成节点答案（预设/追问=调LLM重采样；参考=灰显不可用） | 非参考节点 |
| 重命名 | ✏️ | 节点标题进入内联编辑 | 始终可用 |
| 删除 | 🗑️ | 移出树（Ctrl+Z 可撤销） | 始终可用 |

### 2.4 节点操作

| 操作 | 触发 | 行为 |
|---|---|---|
| 选中 | 单击节点任意位置 | 蓝色背景高亮 |
| 重命名标题 | 双击标题 | 内联编辑 → 回车确认 |
| 编辑内容 | 双击内容区 | textarea 编辑模式（参考/追问节点）→ 点击外部保存 |
| 删除 | 选中 + Delete | 移除节点 + 加入撤销栈 |
| 撤销 | Ctrl+Z | 多步撤销（删除/创建/拖拽）。仅树区域有焦点时生效；输入框/编辑区获得焦点时恢复默认文本撤销 |
| 重做 | Ctrl+Y | 多步重做，同撤销作用域 |
| 创建子节点 | 点击 + 按钮 | 下拉菜单 → 添加参考 / 追问模板 |
|---|---|---|
| 展开/折叠 | 点击 ▶/▼ 三角 | 切换子节点可见性；首次展开预设问题 → 触发 LLM 生成 |
| 刷新节点 | 右键节点标题 → ✨ 刷新 | 等同于换角度，重新调 LLM 生成该节点答案 |

## 3. UI 状态矩阵

### 3.1 全局状态

| 状态 | 触发条件 | 视觉表现 |
|---|---|---|
| **未配置** | 首次使用，无 LLM 配置 | 双击术语 → 弹出设置面板；面板内引导填写 |
| **配置无效** | API Key 错误 / Base URL 不可达 | 设置面板显示错误提示；树中节点显示 "生成中断" |
| **正常** | 配置有效 + 有缓存或首次探索 | 正常交互 |

### 3.2 节点级状态

每个节点（无论是预设子节点还是追问子节点）拥有独立状态：

```
stateDiagram
    [*] --> idle: 节点创建（未展开）
    idle --> loading: 首次展开 / 右键追问
    loading --> streaming: 收到首个 token
    streaming --> done: 流式完成
    streaming --> error: 超时(10s) / 网络错误
    error --> loading: 用户点击 "重试"
    done --> loading: 换角度 / 刷新节点
```

| 状态 | 节点内容区显示 |
|---|---|
| **idle**（未展开/未生成） | 灰色文字 "点击以探索 →" |
| **loading**（等待首个 token） | 脉冲动画占位符 + "正在思考…" |
| **streaming**（逐字输出） | 打字机效果，光标闪烁 |
| **done**（完成） | 完整内容 + 虚下划线渲染 |
| **error**（失败） | 🔴 错误原因 + "点击重试" 按钮 |

### 3.3 按钮/操作状态

| 操作 | 可用条件 | 不可用时表现 |
|---|---|---|
| 输入框回车 | 输入非空 | 空输入 → 无响应 |
| 双击术语 | API 已配置 | API 未配置 → 弹出设置面板 |
| 右键菜单 | API 已配置或术语已缓存 | API 未配置 + 术语未缓存 → 菜单项灰显 |
| 悬停预览 | 术语在缓存中（有直觉字段） | 未缓存 → 无预览，不显示气泡 |

## 4. 异常与边界流程

### 4.1 空状态

| 场景 | 表现 |
|---|---|
| 首页（无任何术语） | 中央引导文案："输入一个概念，开始探索认知的根系" |
| 左侧无足迹 | "在此处追踪你的认知路径" |
| 预设问题未生成 | "点击以探索 →" |
| 自定义追问为空 | 不显示任何占位（追问子节点由用户主动创建） |

### 4.2 错误处理

| 错误类型 | 用户看到的 | 用户可做的 |
|---|---|---|
| LLM 超时 (>10s) | "生成中断：请求超时" + 重试按钮 | 点击重试 |
| API Key 无效 (401) | "生成中断：API Key 无效，请检查设置" + 打开设置按钮 | 修改配置 |
| 额度不足 (429) | "生成中断：API 额度已用尽" + 重试按钮 | 等待或换 Key |
| 网络错误 (fetch fail) | "生成中断：网络连接失败" + 重试按钮 | 检查网络后重试 |
| IndexedDB 写入失败 | 顶部警告横幅："本地存储不可用，刷新后缓存将丢失" | 继续使用（降级为内存缓存） |
| IndexedDB 不可用 | 顶部警告横幅 + 降级为内存缓存（刷新丢失） | 继续使用 |

### 4.3 边界情况

| 场景 | 处理方式 |
|---|---|
| 术语名过长 (>100 字符) | 截断显示 + tooltip 完整术语 |
| 树层级过深 (>6 层缩进) | 横向滚动，左侧缩进区域可滚动 |
| 足迹超过 50 个 | 移除最早节点，显示 "...更早" |
| 单节点内容 >100KB | 截断存储，超出部分折叠 + "展开全部" 按钮 |
| 同时多个节点在 streaming | 支持（不阻塞），各节点独立流式 |
| 生成中切换视角 | 不影响进行中的流式（流式完成后按当前视角缓存） |
| 生成中切换根节点（双击新术语） | 旧节点的流式继续（不中断），新节点独立生成 |
