## M1. 底部输入框 (InputBar)

### 功能目标
页面底部固定栏，统一的文本输入入口。支持双模式切换、历史记录、以及从右键/+按钮自动填充。

### 组件层级

```
InputBar (底部固定栏)
├── 模式切换按钮      🎯 聚焦 / 💬 追问（Toggle）
├── <input>          文本输入框
├── 提交按钮          回车或点击发送
└── 历史下拉列表      最近 20 条（聚焦时显示）
```

### 模式切换规则

| 条件 | 默认模式 | 行为 |
|---|---|---|
| 无根节点 | 🎯 聚焦 | 输入术语回车 → 创建根节点 |
| 有根节点 | 💬 追问 | 输入术语回车 → 追问挂在当前根下 |
| 用户手动切换 | 自定义 | 始终按当前选中模式执行 |

### 交互细节

| 操作 | 行为 |
|---|---|
| 🎯 聚焦模式 → 回车 | 创建/加载 ConceptNode，切换根节点，追加足迹 |
| 💬 追问模式 → 回车 | 创建追问子节点，挂在当前根下，流式生成 |
| 右键 "追问此术语" | 自动切到 💬 模式 + 填入 "${term}是什么？" |
| + 按钮 → 选模板 | 自动切到 💬 模式 + 填入模板展开文本 |
| 聚焦输入框 | 显示历史下拉（若有历史记录） |
| 点击历史项 | 填充到输入框，不自动提交 |
| 输入为空 → 回车 | 无响应 |
| 拖拽文件到输入区 | 触发参考节点创建（见 M7） |

### 状态
- 空：placeholder 根据模式变化（"输入概念探索..." / "追问..."）
- 有历史：聚焦时显示最近 20 条下拉
- 提交中：输入框短暂禁用 + 发送按钮变 loading
- 由右键/+填充：输入框内容被预填，光标在末尾，等待用户编辑

## M2. 递归树 (RecursiveTree)

### 功能目标
核心展示组件。以缩进树形结构渲染概念的递归追问关系。

### 组件层级
```
RecursiveTree (容器)
└── TreeNode (递归组件)
    ├── 展开/折叠三角 (▶/▼)
    ├── 节点标题 (term 或 question)
    ├── 节点内容区
    │   ├── 流式文本 (打字机)
    │   └── TermText (虚下划线术语渲染)
    └── TreeNode[] (子节点，递归)
        ├── 预设子节点 × 4 (intuition/definition/application/motivation)
        └── 追问子节点 × N (custom_qa)
```

### 树结构规则

```
根节点（term）
├── 🌳 动态直觉          ← 预设 1（默认展开，自动生成）
├── 📐 看定义            ← 预设 2（默认折叠，展开时生成）
├── 🔧 看应用            ← 预设 3（默认折叠，展开时生成）
├── 📜 看动机            ← 预设 4（默认折叠，展开时生成）
├── 📖 原文              ← 预设 5（默认折叠，用户手动填充，空时隐藏）
└── 💬 追问1: "X是什么？" ← 追问子节点（用户主动创建）
    └── 💬 追问1.1: ...   ← 追问可嵌套（右键追问 / 拖入）
```

### 预设子节点配置

```typescript
const PRESET_CHILDREN: PresetChild[] = [
  { key: 'intuition',    icon: '🌳', label_micro: '动态直觉',  label_macro: '核心领地',   defaultExpanded: true,  autoGenerate: true  },
  { key: 'definition',   icon: '📐', label_micro: '看定义',    label_macro: '底层逻辑',   defaultExpanded: false, autoGenerate: false },
  { key: 'application',  icon: '🔧', label_micro: '看应用',    label_macro: '现实落点',   defaultExpanded: false, autoGenerate: false },
  { key: 'motivation',   icon: '📜', label_micro: '看动机',    label_macro: '演化路径',   defaultExpanded: false, autoGenerate: false },
  { key: 'source_text',  icon: '📖', label_micro: '原文',      label_macro: '原文',       defaultExpanded: false, autoGenerate: false, draggable: true },
];
```

### 展开/折叠逻辑

```
用户点击 ▶ 三角：
  1. 切换折叠态
  2. 若首次展开 + 该预设问题的缓存字段为 null：
     a. 设置节点状态 = loading
     b. 调用 LLM（选择对应的 Prompt 模板）
     c. 流式渲染 → 完成后状态 = done
     d. 写入 IndexedDB
  3. 若已有缓存：
     a. 直接渲染缓存内容 (<200ms)
     b. 重新渲染 TermText（虚下划线）
```

### 追问子节点

```
用户右键 "追问此术语" (term='算子')：
  1. 在触发节点下追加子节点
  2. 子节点数据结构：
     {
       id: uuid(),
       term: "算子",
       question: "算子是什么？",
       answer: "",        // 流式填充
       parent_node_id: parent.id,
     }
  3. 自动展开 → 流式加载 → 完成 → 持久化
```

### 刷新/换角度

```
用户右键节点标题 → ✨ 刷新 / ⚡ 换角度：
  1. 重新调 LLM（同 Prompt 模板，增加 randomness）
  2. 流式覆盖当前内容
  3. 覆盖 IndexedDB 对应字段缓存
```

## M3. 认知足迹 (FootprintPanel)

### 功能目标
左侧 25% 宽度面板，展示用户跳转历史链，支持快速回溯。

### 组件层级
```
FootprintPanel
├── 标题 "认知足迹"
└── 足迹列表
    └── FootprintItem × N
        ├── 序号/层级线
        ├── 术语名称
        └── 当前焦点高亮标记 (●)
```

### 渲染样式
```
认知足迹
━━━━━━━━━━
  泛函分析
  ├─ 预解式 ●    ← 当前焦点（高亮 + 蓝色左边框）
  └─ 谱集
```

### 交互

| 操作 | 行为 |
|---|---|
| 双击术语（聚焦） | 追加到足迹末尾，current_index 移到末尾 |
| 点击足迹中的历史节点 | 右侧树重置为该节点根状态，截断后续足迹 |
| 足迹超过 50 | 移除最早节点，顶部显示 "...更早" |
| 刷新页面 | 足迹清空 |

## M4. 术语渲染 (TermText)

### 功能目标
将 LLM 返回的文本中的 `[[术语]]` 标记渲染为可交互的虚下划线组件，支持双击/右键/悬停。

### 解析协议

LLM 返回的原始文本：
```
预解式是一个[[算子]]，它描述了[[谱集]]与[[线性变换]]之间的关系。
```

解析后：
```typescript
interface ParsedSegment {
  type: 'text' | 'term';
  content: string;    // 纯文本 或 术语名（不含 [[]]）
}
// → [{type:'text',content:'预解式是一个'}, {type:'term',content:'算子'}, ...]
```

### 渲染

```tsx
// TermText 组件
{segments.map(seg => {
  if (seg.type === 'text') return <span>{seg.content}</span>;
  if (seg.type === 'term') return (
    <span
      className="term-underline cursor-pointer"
      onDoubleClick={() => focusTerm(seg.content)}
      onContextMenu={(e) => showContextMenu(e, seg.content)}
      onMouseEnter={(e) => showHoverPreview(e, seg.content)}
      onMouseLeave={hideHoverPreview}
    >
      {seg.content}
    </span>
  );
})}
```

### CSS
```css
.term-underline {
  text-decoration: underline;
  text-decoration-style: dotted;
  text-underline-offset: 4px;
  color: hsl(var(--primary));
  cursor: pointer;
  transition: color 0.15s;
}
.term-underline:hover {
  color: hsl(var(--primary) / 0.7);
}
```

### 渲染范围与时机
- **范围**：所有已展开节点的答案文本
- **时机**：节点展开时 + 流式输出完成时（不是实时 re-render）
- **性能**：每个节点内容渲染一次，不随状态变化频繁重算

### 悬停预览 (HoverPreview)

```
用户悬停术语 "算子"：
  1. 从内存 Map 查询：termCache.get("算子")
  2. 若有缓存 → 显示气泡：
     ┌─────────────────────────┐
     │ 算子                    │
     │ 像一个筛选器，把输入...  │  ← 动态直觉首句（截断50字）
     └─────────────────────────┘
  3. 若无缓存 → 不显示
  4. 延迟：mouseenter 200ms 后显示
  5. 位置：术语上方/下方（自动判断视口空间）
```

## M5. 视角切换 (ViewToggle)

### 功能目标
右上角 Toggle 开关，在微观/宏观两套预设问题之间切换。

### 组件
```tsx
// 简单 Toggle
<div className="flex items-center gap-2">
  <span>微观</span>
  <Switch checked={isMacro} onCheckedChange={toggleView} />
  <span>宏观</span>
</div>
```

### 行为

```
切换微观 → 宏观：
  1. 仅 4 个预设子节点影响：
     - 标签替换：动态直觉→核心领地 / 看定义→底层逻辑 / 看应用→现实落点 / 看动机→演化路径
     - 已展开预设节点：macro_* 有缓存→替换；无缓存→"点击以探索 →"
  2. 追问节点、参考节点：完全不改动，内容/位置保持不变
  3. 树展开/折叠状态：完全保留
  4. 当前视角存入 React Context（不持久化，刷新回微观）
```

## M6. LLM 配置管理 (SettingsDrawer)

### 功能目标
右侧抽屉面板，用户配置 LLM 连接参数。

### 组件层级
```
SettingsDrawer (shadcn/ui Sheet)
├── 安全警告横幅 "API Key 将明文存储在浏览器本地"
├── API Key 输入框 (type=password)
├── Base URL 输入框 (默认值 "https://api.openai.com")
├── Model 输入框 (默认值 "gpt-4o")
├── Max Tokens 滑块 (默认 1024)
├── Temperature 滑块 (默认 0.7)
├── "测试连接" 按钮
└── "保存" 按钮
```

### 交互

| 操作 | 行为 |
|---|---|
| 填入配置 → 保存 | 写入 localStorage，关闭抽屉 |
| 点击 "测试连接" | 发送极简请求（单 token）验证配置 |
| 测试成功 | 绿色 toast "连接成功" |
| 测试失败 | 红色 toast + 错误详情 |
| 未配置时双击术语 | 自动弹出设置面板 |

### 测试连接实现

```typescript
async function testConnection(config: LLMConfig): Promise<boolean> {
  const res = await fetch(`${config.base_url}/v1/chat/completions`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${config.api_key}`,
    },
    body: JSON.stringify({
      model: config.model,
      messages: [{ role: 'user', content: 'Hi' }],
      max_tokens: 1,
    }),
  });
  return res.ok;
}
```

## M7. 参考节点 (📖 Reference)

### 功能目标
用户手动创建的纯文本/Markdown 节点。通过节点右侧 + 按钮添加，可拖到树中任意位置。挂在根下则视角无关，挂在某四问下则与该问上下文相关。

### 创建方式

```
任意节点右侧 + 按钮 → 下拉菜单 → "📖 添加参考"
  → 在当前节点下创建参考子节点（初始为空 textarea）
  → 用户粘贴/上传文本 → LLM 提取标注术语
  → 标注后的文本可双击/右键交互
```

### 交互

| 操作 | 行为 |
|---|---|
| 首次创建 | 显示 textarea + 上传按钮（空状态） |
| 粘贴/上传文本 | 从用户术语表（localStorage）匹配标注术语，包裹 `[[术语]]`（本地匹配，不调 LLM） |
| 术语未在术语表中 | 不标注（用户可手动加 `[[术语]]`） |
| 双击文中术语 | 聚焦跳转 + 术语追加到术语表 |
| 右键文中术语 | 填入底部输入框（追问模式） |
| 拖拽 📖 节点 | 可拖到树中任意位置（改变归属） |
| 过长文本 | 点击标题旁 📋 图标 → 右侧预览面板展开完整内容 |
| 选中节点 → Delete | 删除参考节点（Ctrl+Z 可撤销） |

### 数据存储

参考节点作为独立的子节点存储（类似 custom_qa，type = 'reference'），随父节点一起持久化到 IndexedDB。

## M8. 预览面板 (PreviewPanel)

### 功能目标
右侧悬浮面板，用于展示任意节点的过长文本内容。不是独立布局元素，而是按需弹出的阅读辅助。

### 触发方式

| 触发 | 行为 |
|---|---|
| 点击任意节点标题旁的 📋 图标 | 弹出/收起预览面板 |
| 参考节点内容过长 | 自动显示 📋 图标 |
| 其他节点内容 > 200 字 | hover 时显示 📋 图标 |

### 布局

```
┌──────────┬───────────────────────┬──────────┐
│ 认知足迹  │     递归树            │ 预览面板  │
│ (25%)    │     (可伸缩)          │ (悬浮)   │
│          │                      │ ┌──────┐ │
│          │                      │ │完整  │ │
│          │                      │ │文本  │ │
│          │                      │ │内容  │ │
│          │                      │ └──────┘ │
└──────────┴───────────────────────┴──────────┘
```

预览面板可拖拽调整宽度，支持虚下划线术语交互（双击/右键）。

## M9. 拖拽重组 (Drag & Drop)

### 功能目标
追问节点和 📖 参考节点可拖拽改变父节点归属。

### 拖拽规则

| 可拖拽 | 可放置目标 | 不可放置 |
|---|---|---|
| 追问子节点 | 任意展开的节点 | 不能拖到自己内部（循环） |
| 📖 参考节点 | 任意节点（含追问节点、预设四问下） | 不能拖到自己内部 |
| 预设四问 | ❌ 不可拖拽 | — |

### 交互

```
hover 节点 → 显示 ⋮⋮ 拖拽手柄
  → 按住拖到目标节点上 → 目标节点高亮
  → 松手 → 节点重挂载 → parent_node_id 更新 → IndexedDB 同步
```

使用 `@dnd-kit/core` 实现。

## M11. 工作组 (WorkGroup)

### 功能目标
项目式术语分组。每个工作组有独立的根术语、树状态、足迹、术语库和导图。组间完全隔离。

### 组件位置
左列顶部：工作组名称下拉 + [+] 新建按钮

### 交互

| 操作 | 行为 |
|---|---|
| 切换工作组 | 下拉选择 → 树/足迹/术语库/导图切换到该组上下文 |
| 新建工作组 | 点击 [+] → 弹出命名对话框 → 创建空组 |
| 重命名 | 右键组名或设置面板中编辑 |
| 删除工作组 | 设置面板 → 工作组 Tab → 删除（含确认） |
| 默认组 | 首次使用时自动创建"默认"工作组 |

### 数据
IndexedDB `work_groups` 表。切换组时从 DB 加载该组的根节点列表和导图缓存。

## M12. 导图 (GuideMap)

### 功能目标
教材目录式层级坐标。展示当前焦点概念在领域中的位置，提供可聚焦的锚点。替代"全局搜索"的角色。

### 触发
聚焦某概念 → Esc / 点 × → 主区域从树模式切换到导图模式

### 组件层级

```
GuideMap (中列主区域，与 RecursiveTree 互斥)
├── 顶部栏 "📖 导图" + [Extend]按钮 + [×关闭]
└── 目录树
    └── GuideMapNode（递归）
        ├── ✓ 标记（术语在术语库中）
        ├── ● 标记（当前焦点）
        ├── 术语名称（可点击聚焦）
        └── 子节点（递归缩进）
```

### 交互

| 操作 | 行为 |
|---|---|
| 首次进入（无缓存） | 显示"生成导图"按钮 → 点击调 LLM 生成 |
| 已有导图 | 显示 Extend 按钮 → 点击增量扩展 |
| 点击导图节点 | 聚焦跳转 + 切换到树模式 + 足迹追加 |
| ✓ 标记 | 该术语已在用户术语库中 |
| ● 标记 | 当前焦点术语 |
| Esc / × | 回到树模式 |
| 右键导图节点 | 🗑️删除节点 / ✏️重命名 / ➕添加子节点 |
| 拖拽导图节点 | 拖到另一节点上 → 改变父子层级（拖到空白处 = 提升到根级） |
| 双击空白处 | 弹出快速添加节点对话框 |

### 编辑模式

导图支持层级编辑（非自由画布），操作模式与树节点一致：
- **手动增删**：右键菜单增删节点
- **拖拽改层级**：拖到目标节点上 → 成为其子节点；拖到空白 → 提升为根级
- **重命名**：右键或双击标题编辑
- 手动编辑后自动标记为"用户已编辑"，Extend 时保留用户修改

### LLM Prompt（模板Tab中可编辑）

```
System:
你是学科体系构建专家。请为一个概念构建教材目录式的知识坐标。
输出严格 JSON 树结构，每层 3-8 个子节点。
遵循以下规则：
1. 从学科顶层逐步细化到该概念所在的子领域
2. 包含同级相关概念（兄弟节点）
3. 层级不超过 4 层
4. 当前概念路径上的节点标记为当前焦点

User:
请为概念"${term}"构建知识坐标。
{extend_mode: 已有导图 JSON + "请在此基础上扩展以下新术语: ${newTerms}"}
```
