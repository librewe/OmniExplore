## 1. 技术栈

| 层级 | 选型 | 版本 | 理由 |
|---|---|---|---|
| 框架 | Next.js (App Router) | 14+ | SSR 可选 + 静态导出 + 文件路由 |
| 语言 | TypeScript | 5.x | 类型安全 |
| 样式 | Tailwind CSS | 3.x | 原子化 CSS，快速迭代 |
| 组件库 | shadcn/ui | latest | 无运行时依赖，可定制 |
| 图标 | Lucide React | latest | 轻量 SVG 图标 |
| 状态管理 | Zustand | 4.x | 轻量，适合客户端状态（LLM 配置） |
| 树状态 | useReducer | React 内置 | 复杂状态逻辑，可预测 |
| 本地存储 | idb (IndexedDB) | 8.x | IndexedDB 封装 |
| LLM 调用 | fetch + ReadableStream | 原生 | 无需额外依赖 |
| 部署 | Vercel | - | 零配置部署 |

## 4. 状态管理方案

### 4.1 Zustand — LLM 配置（全局、持久化）

```typescript
// store/configStore.ts
import { create } from 'zustand';
import { LLMConfig } from '@/types';

interface ConfigStore {
  config: LLMConfig | null;
  isConfigured: boolean;
  setConfig: (config: LLMConfig) => void;
  clearConfig: () => void;
}
```

- 读写 localStorage
- 全局单例

### 4.2 useReducer — 树状态（复杂、可预测）

```typescript
// store/treeStore.ts
interface TreeState {
  rootNodeId: string | null;            // 当前根节点 ID
  expandedNodes: Set<string>;           // 已展开的节点 ID 集合
  nodeStates: Map<string, NodeState>;   // 每个节点的状态
  viewMode: 'micro' | 'macro';         // 当前视角
}

type TreeAction =
  | { type: 'SET_ROOT'; term: string }
  | { type: 'TOGGLE_EXPAND'; nodeId: string }
  | { type: 'SET_NODE_STATE'; nodeId: string; state: NodeState }
  | { type: 'SET_VIEW_MODE'; mode: 'micro' | 'macro' }
  | { type: 'RESET' };
```

### 4.3 useReducer — 足迹（简单）

```typescript
// store/footprintStore.ts
interface FootprintState {
  nodes: PathNode[];
  currentIndex: number;
}

type FootprintAction =
  | { type: 'APPEND'; term: string; nodeId: string }
  | { type: 'NAVIGATE'; index: number };
```

module.exports = nextConfig;
