请根据以下需求开发一个可运行的系统/MVP。

## 1. 技术栈

- **前端框架**：Next.js 14+ (App Router) + TypeScript
- **样式方案**：Tailwind CSS + shadcn/ui 组件库
- **图标库**：Lucide React
- **状态管理**：
  - Zustand：LLM 配置（全局，持久化 localStorage）
  - useReducer：递归树状态 + 足迹状态
- **本地存储**：
  - idb 封装 IndexedDB：概念节点缓存
  - localStorage：LLM 配置 + 输入历史
- **LLM 集成**：OpenAI 兼容 Chat Completions API（`/v1/chat/completions`），SSE 流式
- **部署**：Vercel / 静态导出
- **认证**：无（纯前端，单用户本地使用）

## 2. 产品目标

打造一个"认知考古学"工具——用户输入一个概念，获得：

- 🌳 **动态直觉**：日常类比解释（默认展开）
- 📐 **看定义**：学术严谨定义（折叠，点击展开）
- 🔧 **看应用**：现实应用场景（折叠，点击展开）
- 📜 **看动机**：历史背景与发明原因（折叠，点击展开）

回答中的每个术语都用 `[[术语]]` 标注为虚下划线，支持：
- **双击** → 跳转聚焦（创建新节点 + 追加足迹）
- **右键** → 设为焦点 / 追问此术语 / 换角度
- **悬停** → 显示一句话预览（从缓存提取）

右上角支持**微观/宏观视角切换**，四问内容各自独立缓存。

## 4. 核心功能实现要求

### 4.1 工作组 (WorkGroupSwitcher)
- 左列顶部：组名下拉 + [+] 新建按钮
- 切换组 → 树/足迹/术语库/导图全部切换上下文
- 组间数据完全隔离（IndexedDB `work_groups` 表）
- 首次使用自动创建"默认"工作组

### 4.2 底部输入框 (InputBar)
- 中列底部，含：模式切换 + 输入框 + 发送按钮
- 🎯聚焦 / 💬追问 双模式切换。无根默认聚焦，有根默认追问
- 撤销重做：树区域有焦点时 Ctrl+Z/Y 控制节点操作；输入框/编辑区获得焦点时默认文本撤销

### 4.3 递归树 (RecursiveTree + TreeNode)
- 树节点递归组件，支持无限层级缩进
- 每个根节点下 4 个预设子节点（1 展开 + 3 折叠）
- 每个节点右侧 + 按钮 → 下拉菜单（添加参考 / 预设追问模板）
- 首次展开预设节点 → 触发 LLM；已缓存 → <200ms 直接展示
- 支持同时多个节点流式（互不阻塞）
- hover 节点显示 ⋮⋮ 拖拽手柄（追问/参考节点可拖拽）

### 4.4 导图 (GuideMap)
- Esc / × 切换树⇄导图（中列主区域互斥）
- 教材目录式层级结构，✓标记已探索术语，●标记当前焦点
- 导图为空 → "生成导图"按钮调 LLM；已有 → "Extend"增量扩展
- 点击导图节点 = 聚焦跳转
- **层级编辑**：右键增删节点 / 拖拽改变父子层级 / 双击空白添加节点
- 缓存于工作组 `guide_map` 字段

### 4.5 术语渲染 (TermText)
- 解析 `[[术语]]` → 虚下划线 `<span>`
- 渲染范围：所有已展开节点的答案 + 参考节点内容
- 渲染时机：节点展开时 / 流式完成时 / 参考节点加载完成时

### 4.6 参考节点 (📖 Reference)
- 通过 + 按钮 → "添加参考" 创建
- 粘贴文本后从术语表（localStorage）本地匹配标注 `[[术语]]`，不调 LLM
- 可拖拽到树中任意位置
- 存为子节点（type: 'reference'），随 IndexedDB 持久化

### 4.7 预览面板 (PreviewPanel)
- 右侧悬浮面板，点击节点标题旁 📋 图标弹出/收起
- 展示任意节点的完整文本（无截断），支持虚下划线交互
- 可拖拽调整宽度

### 4.6 拖拽重组 (Drag & Drop)
- 追问节点和 📖 参考节点可拖拽到树中任意位置（改变 parent_node_id）
- 使用 @dnd-kit/core；不能拖到自己内部（循环检测）

### 4.7 右键菜单 (ContextMenu)
- 在虚下划线术语上右键触发
- 三个选项：🎯 设为焦点 / 💬 追问此术语（填入底部输入框） / ⚡ 换角度

### 4.8 悬停预览 (HoverPreview)
- 悬停 200ms 后显示气泡，内容取自缓存动态直觉首句（未缓存则不显示）

### 4.9 足迹面板 (FootprintPanel)
- 左侧 25% 宽度，垂直路径链，当前焦点高亮
- 点击历史节点 → 右侧树回滚 + 截断后续足迹，最多 50 个节点

### 4.10 视角切换 (ViewToggle)
- 右上角 Switch 开关，仅 4 个预设四问内容替换
- 追问/参考节点保留不动，树展开状态完全保留
- 缓存独立（micro_* ≠ macro_*）

### 4.11 术语库 (TermLibrary)
- 左侧栏第二个 Tab，展示已积累术语列表
- 支持搜索/点击聚焦/删除术语
- 数据来源：localStorage `term_list`

### 4.12 设置面板 (SettingsPanel)
- 左下 ⚙️ 唤起，纵向 Tab 在左侧
- **LLM 连接**：API Key / Base URL / Model / Max Tokens / Temperature / 测试连接
- **模板**：全部 Prompt 模板可编辑（含名称本身）——微观4+宏观4+追问默认++按钮模板列表
- **术语库**：术语列表管理（搜索/删除）
- **工作组**：创建/重命名/删除工作组
- 关闭后工作台状态不变，修改即时生效

### 4.13 节点操作
- 单击选中（蓝色高亮）→ Delete 删除
- 双击标题 → 内联重命名；双击内容区 → 编辑模式
- 右键节点 → ✨刷新此节点 / ✏️重命名 / 🗑️删除（参考节点"刷新"灰显）
- Ctrl+Z 撤销 / Ctrl+Y 重做（仅树区域有焦点时；编辑文本时默认行为）

## 6. LLM 集成

### Prompt 模板

**微观-动态直觉**：
```
System: 你是认知科学解释专家。用日常动作类比解释概念。用 [[术语]] 标注专业术语。不使用公式。100-200 字。
User: 请用动态直觉解释概念："${term}"
```

**微观-定义**：严谨学术定义 + LaTeX 公式（`$formula$`）+ [[术语]] 标注

**微观-应用**：1-2 个具体场景 + [[术语]] 标注

**微观-动机**：历史背景 + 要解决的问题 + [[术语]] 标注

**宏观四问**：核心领地 / 底层逻辑 / 现实落点 / 演化路径（完整 Prompt 模板见 `doc/05-LLM与Prompt.md` 第 2.5-2.8 节）

**自定义追问**：
```
System: 在父概念"${parentTerm}"语境下解释"${term}"。结合上下文，用日常类比，标注新术语。
User: 在"${parentTerm}"的语境下，"${term}"是什么？
```

## 7. 交互与状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| loading | LLM 等待首 token | 脉冲动画 + "正在思考…" |
| streaming | 收到 token | 打字机 + 光标 |
| done | 完成 | 完整内容 + 虚下划线 |
| error | 超时/网络/API 错误 | 错误原因 + "点击重试" 按钮 |
| empty | 未展开/首页 | "点击以探索 →" / 引导文案 |

## 8. 验收标准

1. ✅ 输入术语 → 自动生成动态直觉，5 秒内开始流式输出
2. ✅ 双击回答中的术语 → 左侧追加足迹 + 右侧切换根节点
3. ✅ 右键"追问此术语" → 追加子节点 + 流式生成，不阻塞其他节点
4. ✅ 已缓存节点展开延迟 < 200ms
5. ✅ 视角切换后，已缓存的预设答案正确替换
6. ✅ 左侧点击历史节点 → 右侧回滚 + 足迹截断
7. ✅ LLM 超时 → 显示重试按钮，不崩溃
8. ✅ 未配置 API → 弹出设置面板，不崩溃
9. ✅ 刷新页面 → 缓存节点正常展开（IndexedDB）
10. ✅ 足迹不跨 session（刷新清空）
