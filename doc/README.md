# OmniExplore — 认知考古学工具

> **核心理念**：理解 = 沿着概念根系递归追问
>
> 一个纯前端认知探索工具。用户输入概念 → 获得四个维度的解释 → 回答中每个术语都可继续下钻，形成无限深度的递归知识树。左侧记录跳转足迹，右侧展示认知根系。

## 项目快照

```
产品形态    纯前端 SPA（无登录、无后端）
用户角色    大学生、自学者、跨领域研究者
核心操作    输入概念 → 递归追问 → 双击跳转 → 足迹回溯
LLM 方案    可配置多模型（OpenAI 兼容 API），用户自填 Key
存储方案    IndexedDB（节点缓存）+ localStorage（配置）
技术栈      Next.js 14 + TypeScript + Tailwind CSS + shadcn/ui
部署        Vercel / 静态导出
```

## 关键术语

| 术语 | 定义 |
|---|---|
| **聚焦 (Focus)** | 双击术语 → 左侧追加足迹 → 右侧树根节点切换为该术语 → 创建独立 ConceptNode |
| **追问 (Inquire)** | 右键术语 → 在当前节点下追加子节点 → 生成 Q&A 对，存入父节点的 custom_qa 数组 |
| **换角度 (Resample)** | 右键节点 → 对该节点的答案重新调用 LLM，覆盖原缓存 |
| **预设四问** | 每个 ConceptNode 的 4 个 LLM 生成维度：动态直觉/定义/应用/动机（微观）或领地/逻辑/落点/演化（宏观） |
| **参考 (Reference)** | 通过 + 按钮手动创建的纯文本节点，可拖拽到树中任意位置，内容经 LLM 标注术语后可交互 |
| **虚下划线** | 回答中用 `[[术语]]` 标注的可交互文本，支持双击聚焦/右键填入输入框追问/悬停预览 |
| **拖拽重组** | 追问和参考节点可拖到树中其他位置，改变父节点归属 |
| **+ 按钮** | 每个节点右侧的创建入口，下拉菜单含"添加参考"和用户自定义追问模板 |
| **工作组 (WorkGroup)** | 项目式术语分组，组间树/足迹/术语库/导图完全隔离 |
| **导图 (GuideMap)** | 教材目录式层级坐标，Esc 切换树⇄导图，提供可聚焦的锚点，✓标记已探索 |
| **设置面板** | 左下⚙️唤起，纵向Tab在左：LLM连接/模板/术语库/工作组 |
