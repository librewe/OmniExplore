# 2 视图层

## 2.1 知识树视图 

### 知识树
从**根节点**开始，通过**子节点**层层展开的结构，只有视图和数据，没有交互。用户会通过点击**术语**（或**聚焦**文本产生术语）的方式切换到某个**知识树**视图。知识树视图是常驻的，只会在不同根间切换，除了一开始什么根节点都没有而显示**引导**界面。

### 根节点（或称术语）
与**子节点**不同，根节点没有“内容”。
| 交互 | 描述 |
|---|---|
| 输入框创建 | 在**输入框**输入词汇，若不存在，作为新**术语**入库，以此为根节点创建一个新知识树 |
| 从划词创建 | 在**子节点**文本中划词选中内容，后右键菜单“**聚焦**”创建新的根节点（也就是跳转到新的知识树视图），这样产生的术语会被加入术语库 |
| 从术语库创建 | 在术语库模块，可以创建新的术语，从而点击跳转到它的知识树视图 |
| 右键重命名 | 编辑根节点，也就是编辑**术语** |
| 右键新增空子节点 | 参见“创建空子节点” |
| 点击加号 | 参见“从预设创建子节点” |

### 子节点
所谓子节点是[标题|内容]这样的数据结构，子节点也可以有子节点。子节点可以拖动而改变归属关系。
（当不在编辑时）右键子节点区域（而又不触发划词右键菜单时）：
| 交互 | 描述 |
|---|---|
| 拖动 | 在拖拽手柄拖动可以拖到树中其他位置，改变父节点归属 |
| 右键编辑 | 进入展开状态，并编辑节点内容，为了简单起见，拼接问答后取内容第一行截断 15 chars作为标题渲染（比如**从预设创建**就可以把“预设提示词\n模型回答”作为内容）；当点击非编辑区域的其他位置时，自动退出编辑，并恢复原来的展开/收起状态 |
| 右键展开/收起 | 展开/收起子节点的内容，简单起见，就不做新按钮了，但是可以右键操作，当展开时显示的是收起按钮，收起时显示的是展开按钮。收起时只展示标题，展开时显示完整内容（这时候好像就没必要展示标题了） |
| 右键新增空子节点 | 参见“创建空子节点” |
| 右键删除 | 递归删除节点，需要二次确认 |
| 点击加号 | 参见“从预设创建子节点” |

#### 从预设创建子节点
| 交互 | 描述 |
|---|---|
| 创建 | 点击**根节点**或**子节点**旁的加号选择加号菜单中的“生成定义”（之类的），然后会把提示词覆盖到**输入框**中，并自动切换tag，用户按下ctrl+回车发送后就会在tag对应的节点下创建一个新的子节点 |
| tag |**输入框**会常驻显示一条“追加到[根节点名字]” 的小tag，当鼠标左键或右键点击（或者因为选取文本而实际触发“拖拽”事件）某个子节点时（子节点因此出现选中高亮，悬浮高亮也要做，注意区别）这个小tag也会自动切换为“追加到[子节点标题]”|

注意区分 **（从预设创建）加号下拉菜单** 和 **划词选中子节点内容右键菜单** 和 **子节点本身右键菜单** 和 **根节点右键菜单**，四个菜单。只有前两个菜单的条目名和对应提示词可以在设置模块中进行配置（两套）。
这里的提示词是带参数的，简单起见，可以先用“{}”占位表示对应内容，例如第一个菜单提示词中的“{}”就代表根节点，第二个菜单提示词中的“{}”就代表划词选中的内容，只有写入输入框时才会使用真实内容，在菜单显示时使用占位符。
无论配置如何，第一、三、四个菜单（三、四统称为**右键菜单**）会包含“创建空子节点”，第二个菜单会包含“聚焦”。
用户可在配置中拖动改变第一二个菜单条目的顺序（因此第三四个菜单无须出现在用户配置层）。

#### 从划词创建子节点
（非编辑区域）鼠标划词选中一段**子节点**内容文本后，可从右键菜单创建的子节点
| 交互 | 描述 |
|---|---|
| 创建 | 在选中的文本区域右键，展示划词选中子节点内容右键菜单，包括“聚焦”和“可配置选项” |
| tag | 因为选中一定会点击到子节点，所以tag会自动切换为“追加到[子节点标题]”；但是要是用方向键切换呢？不可能，这样只会在子节点本身之间切换，无法选中内容。所以应该无需其他处理。|
#### 创建空子节点
| 交互 | 描述 |
|---|---|
| 创建 | 从**加号下拉菜单**或者**右键菜单**创建空子节点，通过编辑它达到不在输入框也能输入纯文本的目的 |

## 2.2 导图视图
用户可以在导图视图与知识树视图之间切换。
为了简单起见，导图所谓的“图”只是一种集合，不含边关系。这样大大降低了渲染复杂度。
简单起见，导图视图先不设右键交互。
### 导图
| 交互 | 描述 |
|---|---|
| **defocus** | Esc 进入导图视图，再次 Esc **defocus**，点“返回”按钮可以返回Esc前的视图。所谓defoucus是，当当前视图有两个及以上的节点，且不在子图中时，defocus创建一个这些节点的组，并在一个更大的图中以**图节点**显示这个组。 |
| **focus**即聚焦 | 双击或者单击后再次点击一个**图节点**进入它的图视图，或一个**根节点**进入知识树视图。单击会在**预览面板**显示图节点含有的节点列表，或者根节点的仅显示子节点标题的知识树|
| 编辑 | 增删节点 / 拖拽改变层级 / 重命名 / 拖拽组合节点，详见**节点**描述。 |




### 节点
在导图视图下，节点指图节点和根节点，图节点可以作为集合包含两种节点作，但根节点不能。
|拖拽交互|功能|
|---|---|
|根节点→根节点|组合|
|根节点→图节点|归入|
|图节点→根节点|组合|
|图节点→图节点|组合|
|节点移出图区域：当处在图节点视图时，渲染一个约占90%导图视图区域图区域框，当节点移出该框时，触发移出操作，移除该节点的渲染，但无需在框外渲染（因为当前是这个图节点的视图，无需框外的信息）|移出|

### 预览面板
简单起见，知识树视图下的面板可以留空，只做导图视图下的面板（是预览面板）。
显示图节点含有的节点列表，或者根节点的仅显示子节点标题的知识树

## 2.4 导航
导航属于视图层，表现为左侧栏。在此可以新建工作组，或者展开某个工作组查看其下的根节点列表，点击某个根节点即可切换到该根节点的知识树视图。

### 工作组
工作组是根节点/术语管理的单位，产生的根节点会以列表展示在工作组文件夹下。
**术语标注**限制只检测当前工作组内的术语。
#### 术语标注
是指在子节点内容或标题或预览面板中匹配术语，然后渲染下划线，鼠标悬浮时变成经典链接跳转手势，点击会聚焦（跳转其知识树视图）。
