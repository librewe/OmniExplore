# 01 · 需求澄清

> 产品定位、用户场景、需求决策清单

---

## 1. 产品一句话定位

一个"认知考古学"工具——沿着概念根系递归追问，将陌生术语层层降解到日常经验。【用户确认】

## 2. 核心问题

现有学习工具（百科、教材、图谱）只提供"扁平解释"或"静态分类"，无法支持用户沿着疑惑点层层剥开术语包装，直到露出日常经验。

## 3. 用户与场景【用户确认】

| 维度 | 内容 |
|---|---|
| 主要用户 | 大学生、自学者、跨领域研究者 |
| 使用场景 | 在顶部输入框输入概念/术语，开始递归探索 |
| 核心目标 | 3 次点击内将一个陌生术语降解到初中生能理解 |
| 输入方式 | 中列底部输入框（🎯聚焦/💬追问 双模式切换）+ 节点右侧 + 按钮创建参考/预设追问 |
| 布局 | 左列(工作组+足迹/术语库+⚙️) + 中列(视角+树⇄导图+输入框) + 右列(预览面板悬浮) |
| 工作组 | 项目式隔离，IndexedDB 独立表。切换组=切换树/足迹/术语库上下文，顶部栏切换 |
| 导图 | 教材目录式层级坐标。Esc 切换树⇄导图，手动生成/Extend(增量扩展LSM)，✓标记已探索术语 |

## 4. 产品形态决策

| 决策项 | 决策 | 标签 |
|---|---|---|
| 产品形态 | 纯前端 SPA，无登录，无后端 | 【用户确认】 |
| 部署方式 | Vercel / 静态导出 | 【合理假设】 |
| 多用户 | 不支持，单用户本地使用 | 【用户确认】 |
| 移动端 | MVP 仅 Desktop Web | 【暂不纳入】 |

## 5. 数据与存储决策

| 决策项 | 决策 | 标签 |
|---|---|---|
| 节点缓存 | IndexedDB，永久保存 | 【用户确认】 |
| LLM 配置 | localStorage（明文，顶部警告） | 【合理假设】 |
| 足迹 | React State（不跨 session），按工作组隔离 | 【用户确认】 |
| 输入历史 | localStorage，最近 20 条 | 【合理假设】 |
| 工作组 | IndexedDB 独立表 `work_groups`：名称/根术语列表/导图缓存 | 【用户确认】 |
| 术语表 | localStorage `term_list`，聚焦自动追加，参考节点本地匹配 | 【用户确认】 |

## 6. LLM 方案决策

| 决策项 | 决策 | 标签 |
|---|---|---|
| 模型 | 可配置（OpenAI 兼容 API），用户自填 Key/URL/Model | 【用户确认】 |
| 术语抽取 | 一次调用：Prompt 要求 LLM 用 `[[术语]]` 标注 | 【用户确认】 |
| 流式输出 | SSE / ReadableStream → 打字机效果 | 【用户确认】 |
| 超时 | 10 秒，不自动重试 | 【用户确认】 |
| 上下文 | 仅携带当前节点名 + 父节点名 + 视角模式 | 【用户确认】 |

## 7. 交互行为决策

| 决策项 | 决策 | 标签 |
|---|---|---|
| 追问 = 轻量 Q&A | 追问产生的子节点仅作为父节点 custom_qa 中的记录，不创建独立 ConceptNode | 【用户确认】 |
| 聚焦 = 独立节点 | 双击聚焦才创建新的独立 ConceptNode（拥有自己的预设四问） | 【用户确认】 |
| 缓存命中 | 直接展示已缓存内容，不重新调 LLM | 【用户确认】 |
| 虚下划线范围 | 整棵树所有已展开节点的回答都渲染 `[[术语]]`，展开/折叠时触发重新渲染 | 【用户确认】 |
| 换角度 | 所有节点类型都支持重新生成（LLM 重新采样），不限于根节点动态直觉 | 【用户确认】 |
| 悬停预览 | 从该术语已缓存的「动态直觉」提取第一句；未缓存则无预览 | 【用户确认】 |
| 拖拽改归属 | 追问子节点和 📖 参考节点可拖到树中任意位置，改变父节点归属 | 【用户确认】 |
| 双击行为 | 任何位置的虚下划线术语双击 = 聚焦跳转（切换根节点） | 【用户确认】 |
| 右键追问 | 右键术语 → 底部输入框填入术语 → 用户编辑 → 回车 → 追问挂在发起右键的位置 | 【用户确认】 |
| + 按钮 | 所有节点右侧 + 按钮 → 下拉菜单：📖 添加参考（纯文本） + 用户预设追问模板 | 【用户确认】 |
| 视角切换 | 仅四问内容切换（微观↔宏观），追问/参考节点保留不动，树展开状态不变 | 【用户确认】 |
| 输入模式 | 底部输入框 🎯聚焦/💬追问 切换。无根默认聚焦，有根默认追问，可手动切 | 【用户确认】 |
| 删除节点 | 选中节点 → Delete 键删除 → Ctrl+Z 可撤销，Ctrl+Y 重做（多步撤销栈） | 【用户确认】 |
| 右键范围 | 两套独立菜单：划词右键（虚下划线术语）+ 节点右键（节点标题/内容区） | 【用户确认】 |
| 节点右键菜单 | ✨刷新此节点 / ✏️重命名 / 🗑️删除（参考节点的"刷新"灰显） | 【用户确认】 |
| 标题编辑 | 所有节点标题双击可重命名（内联编辑） | 【用户确认】 |
| 内容编辑 | 双击内容区进入编辑模式（参考/追问节点可编辑，预设四问通过刷新重生成） | 【用户确认】 |
| 节点选中 | 单击节点 → 蓝色高亮选中态 → 可执行 Delete 等操作 | 【用户确认】 |
| 术语表 | 每次双击聚焦的术语追加到用户级术语表（localStorage）。参考节点粘贴时从术语表匹配标注，不调 LLM | 【用户确认】 |
| 预览面板 | 单例，点击新节点 📋 替换内容 | 【用户确认】 |
| 撤销 | Ctrl+Z 多步撤销（删除/创建/拖拽）。仅当焦点在树区域时生效；输入框/编辑区获得焦点时恢复默认文本撤销行为 | 【用户确认】 |
| 导图切换 | 聚焦某概念 → Esc 进入导图模式（教材目录式坐标），再按 Esc/× 回到树模式 | 【用户确认】 |
| 导图生成 | 导图视图为空 → "生成导图"按钮调 LLM；已有导图 → "Extend"按钮增量扩展（传入已有导图+新术语） | 【用户确认】 |
| 导图交互 | 点击导图节点 = 聚焦跳转；✓标记 = 术语已在术语库中；导图节点不加入足迹 | 【用户确认】 |
| 导图编辑 | 层级编辑模式：右键增删节点 / 拖拽改变层级 / 重命名 / 双击空白添加节点 | 【用户确认】 |
| 初始界面 | 居中引导页：输入框 + 欢迎文案 + 最近术语入口。首次使用自动创建"默认"工作组 | 【用户确认】 |
| 多根节点 | 工作组内所有被聚焦过的术语都是根（`root_term_ids`），足迹切换活跃根，同一时间只显示一个根的树 | 【用户确认】 |
| 跨组缓存 | ConceptNode 全局共享（MD5）。同术语同问法优先查缓存，省 LLM 成本。刷新可覆盖 | 【用户确认】 |
| 首次引导 | 首次打开时 3-5 个 tooltip 依次引导：输入概念→展开节点→双击聚焦→右键追问→Esc导图 | 【用户确认】 |
| 工作组切换 | 顶部栏下拉切换 → 树/足迹/术语库/导图全部切换到该组上下文，组间完全隔离 | 【用户确认】 |
| 设置面板 | 左下⚙️唤起，纵向Tab在左：LLM连接/模板/术语库/工作组 | 【用户确认】 |
| 模板Tab | 全部Prompt可编辑（含名称本身）：微观4+宏观4+追问默认++按钮模板列表 | 【用户确认】 |

## 8. 预设子节点与视角切换

每个 ConceptNode 创建时自带 4 个预设 LLM 子节点（微观/宏观各一套答案）。第 5 个"参考"节点通过 + 按钮手动创建，可拖到任意位置。

### 微观四子（默认视角）

| 维度 | 图标 | 触发时机 | 默认状态 | 内容定位 |
|---|---|---|---|---|
| 动态直觉 | 🌳 | 根节点创建时**自动生成** | 展开 | 用日常动作类比描述概念的核心运行机制 |
| 看定义 | 📐 | 用户**首次点击展开**时生成 | 折叠 | 严谨表述（公式/学术定义，LaTeX 渲染） |
| 看应用 | 🔧 | 用户**首次点击展开**时生成 | 折叠 | 具体落地场景/现实对应物 |
| 看动机 | 📜 | 用户**首次点击展开**时生成 | 折叠 | 发明原因/历史派系纠葛/要解决的具体麻烦 |

### 宏观四子（切换视角后）

| 维度 | 图标 | 触发时机 | 默认状态 | 内容定位 |
|---|---|---|---|---|
| 核心领地 | 🗺️ | 切换至宏观 + 首次展开时生成 | 折叠 | 该概念在所属学科中占据什么生态位，与哪些子领域接壤 |
| 底层逻辑 | 🧱 | 切换至宏观 + 首次展开时生成 | 折叠 | 剥离术语包装后，依赖的最基础假设（第一性原理） |
| 现实落点 | 🏭 | 切换至宏观 + 首次展开时生成 | 折叠 | 如何从学术界渗透到产业界，改变了什么产品/流程/决策 |
| 演化路径 | 🕰️ | 切换至宏观 + 首次展开时生成 | 折叠 | 从谁最早提出，经历哪些关键转折，当前前沿在研究什么 |

> 微观与宏观四套答案各自独立缓存。切换视角时**仅四问内容替换**，追问/参考节点保留不动，树展开状态不变。

### 参考节点（用户手动创建）

| 维度 | 图标 | 创建方式 | 内容定位 |
|---|---|---|---|
| 参考 | 📖 | 任意节点 + 按钮 → "添加参考" | 用户自己的纯文本/Markdown 阅读材料。粘贴近 LLM 标注术语后可交互探索。可拖到树中任意位置——挂在根下则视角无关，挂在某四问下则与该问相关 |

### 追问节点（用户主动追问）

| 创建方式 | 流程 |
|---|---|
| 右键术语 → 追问 | 术语填入底部输入框 → 用户编辑 → 回车 → 追问挂在发起右键的节点下 |
| + 按钮 → 选择预设模板 | 模板自动填入输入框 → 用户编辑 → 回车 → 追问挂在 + 所在节点下 |
| 底部输入框（追问模式） | 直接输入问题 → 回车 → 追问挂在当前根下 |

## 9. 后续规划（MVP 之后）

| 功能 | 优先级 | 说明 |
|---|---|---|
| 浏览器插件（划词触发） | 🔴 高 | 选中网页文本 → 右键 → 一键跳入应用并聚焦。是产品形态的自然延伸 |
| 移动端适配 | 🟢 低 | 响应式布局，触摸交互替代右键 |

## 10. 暂不纳入

- 用户系统 / 登录 / 多设备同步
- 多用户协作 / 分享链接
- 导出思维导图 / PDF
- 语音输入
- PDF 上传解析
