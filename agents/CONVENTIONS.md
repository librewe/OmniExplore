# OmniExplore 行为契约

> 交互/渲染/流式/配置的意图与防坑约定：改动相关行为前按涉及范围读对应小节。只记代码读不出的意图与约束，实现细节以 src/ 为准。新约定实装后回写本文件。

## 输入与提交

- tag 显示当前追加目标：选中 Session 显示其标题，否则显示当前 Node 标题。提交判定为「有目标或强制新建 → 创建；否则回车只是聚焦 Node」。
- 回车 / Ctrl(⌘)+回车发送，Shift+回车换行，输入法组合中回车不提交。
- 输入草稿绑定追加目标：目标切换即清空；程序化填充只写入切换瞬间，不残留到新目标。
- 空态不渲染底部输入栏，由居中输入框承担聚焦。
- tag 形态随视图：外层隐藏并强制新建根 Session；内层显示；导图表示「在当前层级新增节点」。外层新建根 Session 后自动进内层看流式。
- 外层目录输入栏有起始模式切换：Ask（标签取当前 config.model）提交即调模型生成 qa；From scratch 不调模型，落一条 note，与 Ask 同样自动建根会话并进内层。默认 Ask，切 Node 或离开外层随输入栏 remount 重置为 Ask。仅外层启用，内层/导图无此按钮。

## 新建与会话

- 根 Session 加号为固定五预设，system 一次性注入；模板 `${node}` 发送前替换为当前 Node 标题。普通 Session 加号用可自定义菜单项。
- 加号并入 Session 末尾的追加行，仅当前追加目标 Session 显示；子 Session 标签 hover 显折叠 chevron，fork/撤回/copy 等行操作 hover 显隐。
- fork 分支按序编号命名（内层展示为 `#N` 定长标签），fork 后自动展开、选中并滚动定位到新分支。

## 选中与追加

- 聚焦 Node 默认选中首个根 Session；点空白不取消。
- 选中 Session 时末尾显示「将追加到这里」提示线，与加号同行；仅内层树视图可见。
- entry 与 session 选中独立共存：entry 高亮优先；点 entry 同步选其所属 Session，点子 Session 标签清 entry 并滚到该节末尾。

## 划词与右键

- 划词弹菜单，模板占位符：`${selected}` 选中文本，`${root}`/`${node}` 当前 Node 标题；点击后从源 entry fork 分支并填入输入框。
- 无 entry 上下文的划词回退当前 Node；未选中 Session 时提交自动建根 Session。
- 内容区/PDF/术语标注不拦截浏览器默认右键。
- 防重弹：同文本已弹菜单不重复弹；菜单位置取选区几何而非鼠标坐标。

## 导航与视图

- 聚焦 Node 默认落外层目录；点标题或段摘要进内层。内层 Esc 退外层并重置追加目标；组合视图沿面包屑退出。
- 外层为根 Session 卡片列表，子分支紧凑列表不套卡片；默认展开根 Session 第一层。
- 目录/内层滚动容器预留滚动条宽度防跳动，导图用无占位滚动区。
- 导图有不可见虚拟根承载平级顶层；面包屑仅导图显示。

## 渲染与行操作

- Entry 无独立标题行：行即 userInput 本身。展开的 qa 把问题移出限高 viewport（过长默认收起，左下角「展开/收起」），viewport 只含回答；折叠时 clamp 2 行。空 note 显示占位文案。展开 chevron 在行前沟槽、hover 显现；行操作（撤回/复制/分支）在内容末的预留空行、左对齐、hover 显现。
- 双击编辑仅笔记：命中术语则让位；提问不参与双击编辑，只能经撤回或右键「编辑」进入。
- 撤回即编辑：复原原输入文本，保存/取消语义同编辑。
- 编辑框自动增高，超过 360px 限高转框内滚动；不再手动拖拽缩放。
- Session 重命名与删除走右键；子 Session 标签不支持双击改名。
- summary 与普通 entry 同形（真实摘要文本），生成中强制展开、完成后尊重手动折叠；渲染在 fork 源 entry 之后、子 Session 之前；用户编辑过后 AI 不得覆盖。
- reasoning 为默认收起的「思考过程」块，流式中展开显示进行态。
- 长回答：输出完成后超视口比例才套内部限高滚动；流式期间不限高，完成仍超出再限高并锚到顶部。块内滚到边界后滚轮交还外层容器。
- 滚动位置仅内存瞬时记忆：内容块以 entry 身份、容器以视图槽位，切换往返还原，不落持久化。
- 行级不用填充色（无 hover/选中底色、无祖先 tint）；选中态左侧蓝色竖线已移除。保留：问的 muted 底框、session 标签底色、灰色缩进竖线（跨整个 entry 内容）。粘滞的 Session 标签为不透明 chip，无渐隐遮罩。

## Markdown 与术语

- 层级靠字重而非字号区分；标题与表格字号不小于正文。
- 行距类名须写在样式合并末位，否则被同组类覆盖删除。
- 公式仅识别 `$`/`$$`：渲染前将 `\[...\]`、`\(...\)` 归一化为 `$` 形式，只匹配带 `\` 前缀括号。
- 术语保护必须覆盖 markdown 链接、公式与代码，否则占位符破坏原文；公式转义在归一化阶段，故注入时即纳入保护。
- 自由术语匹配：首尾均为 ASCII 词字符的术语要求词边界，避免 RL 命中 World 内部的 rl；含 CJK 的术语保持子串匹配，中文无词边界。
- 术语单击聚焦；按下时若选区非折叠（拖选）则不触发，让位划词菜单。
- 内层 Session 标签（root 与子 `#N`）悬浮在所在节首行左端、不占行高：粘滞锚点 `height:0`+`top=0`，chip 绝对定位 `-left-10 top-2`；各层标签横向并排共占一行、无渐隐遮罩；外层目录粘滞按原行秩。视觉数值见代码。

## 流式

- 连接超时只覆盖建连阶段，收到响应头即清除；流式过程不设总体超时，防长回复被腰斩。
- 空闲看门狗：持续无帧超时中止，防 entry 永久停在流式中。
- 流式内容整值累积设值非增量追加，防重复。
- 流式产出结构化块，改动需同步全部调用方；支持外部中止，中止真正取消请求并保留已生成内容。
- 新流自动打断旧流：旧 entry 保留部分内容置完成态，不留永久转圈。
- 段摘要只消费正文，不消费思考过程。

## LLM 配置

- 设置仅暴露 API Key / Base URL / Model。
- `temperature` 不再发送；thinking 与 reasoning 共享 token 预算，采样参数被忽略。
- 思考参数格式按网关识别，不强行附加以免报错；带工具调用时必须回传历史 reasoning，否则 400。

## 悬停预览与 PDF

- 悬停预览不拦截鼠标事件防卡滞；展示对应 Node 首行摘要，点击任意处关闭。
- pdfjs-dist 锁定 4.x 勿升 5.x/6.x；worker 走 CDN 且版本与主库一致。PDF 划词走划词菜单，无右键菜单。

## 组合视图

- 图节点 `nodeId` 仅叶子持有并绑定主题 Node，定位唯一按 nodeId、无标题回退；组合后叶子保留在分组内，分组自身无 nodeId。
- 构造时按标题找绑定，找不到为自由节点；旧数据无绑定，重建后全量补绑。

## 主题与工作组

- 主题三态切换，localStorage 持久化，首帧内联脚本防闪。
- 节点库/组合视图/导航历史按工作组隔离，Node 归属工作组、根 Session 继承；切组重置视图与追加目标并重载节点。
- 节点库按内容更新时间降序排列：取整棵会话树内最近的 session.updated_at，新建与重命名 Session、增改 entry 均刷新；Node 重命名不触碰 Session，不计入排序。
- 列表选中态用实心 accent 底 + accent-foreground 字，悬浮态用 accent 半透明底，保证「选中浓、悬浮淡」在明暗两态一致。
