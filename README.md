# OmniExplore

> 一个模型对话交互优化原型。以原地缩进的对话分支呈现为设计特色。

## 它能做什么

- **目录回访**：Fork 时自动生成段摘要，提供会话历史的目录导航。
- **划词聚焦**：选中任意文字可聚焦为新主题，内容中自动标注已有主题，点击即可跳转。
- **组合视图**：多个主题可嵌套组合管理，提供整体关系图景。

## 快速体验

无需部署，直接打开 <https://librewe.github.io/OmniExplore/>，配置 API Key 后即可使用。

## 隐私与数据

- 纯前端静态站点，无账号、无后端、无任何云端同步
- 对话与文件全部存储在浏览器本地，Key 按站点隔离存于当前浏览器
- 注意：清除浏览器站点数据会一并删除全部内容
